# บทและลำดับการสาธิต (คลิปไม่เกิน 3 นาที)

> **สถานะ: ยังต้องอัดคลิป** ไฟล์นี้คือบท ลำดับหน้าจอ และรายการที่ต้องเห็นในคลิป
> ทุกข้อความที่พิมพ์ในบทนี้มีผลทดสอบจริงอยู่ใน [TEST_RESULTS.md](TEST_RESULTS.md) แล้ว
> คำตอบของโมเดลอาจใช้คำต่างจากผลทดสอบเล็กน้อยในแต่ละครั้ง (โมเดลไม่ deterministic) แต่สาระต้องเหมือนกัน

## เตรียมก่อนอัด

1. `python run.py` แล้วรอจนขึ้น `Application startup complete`
2. เปิดหน้าต่างเบราว์เซอร์ใหม่ (หรือ Incognito) เพื่อให้แชทเริ่มจากศูนย์ ขนาดหน้าต่างประมาณ 1280×800
3. เตรียมไฟล์รูปไว้บนเดสก์ท็อป: `docs/test-images/img1-deposit-slip.png` และ `img4-injection-note.png`
4. แท็บที่สอง: `http://localhost:8051/admin` ล็อกอิน `owner@blinksb.co` / `demo1234` แล้วเปิดเมนู Conversations ค้างไว้
5. ปิดการแจ้งเตือนของเครื่อง และซ่อนบุ๊กมาร์กที่มีข้อมูลส่วนตัว
